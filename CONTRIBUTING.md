# Contributing

This repository works directly against `main`, not a `dev` branch.

Questions and ideas: start them in [Morpheus Discussions](https://github.com/orgs/MorpheusAIs/discussions).

Changes: fork from `main` and open a pull request into `main`.

See also the organization [CONTRIBUTING](https://github.com/MorpheusAIs/.github/blob/main/CONTRIBUTING.md).
